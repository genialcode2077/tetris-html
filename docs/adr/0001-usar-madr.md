# 0001 · Registrar decisiones con MADR

- Estado: aceptado · Fecha: 2026-09-07

## Contexto

Varios agentes/humanos retomarán el proyecto; necesitan saber _por qué_ se decidió cada cosa.

## Decisión

Usar MADR 4.0 (mínimo: contexto, opciones, decisión, consecuencias) en `docs/adr/NNNN-slug.md`, índice en `docs/adr/README.md`.

## Consecuencias

Cada cambio de contrato o dependencia nueva requiere ADR. Coste bajo; trazabilidad alta.
